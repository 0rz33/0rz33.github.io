硬盘动态扩容 LVM

查看指定目录的大小

传统的文件系统是基于分区的, 一个文件系统对应一个分区, 这种方式比较直观, 但不易改变：

  1. 不同的分区相互独立, 单独的文件不能跨分区存储, 容易出现硬盘的利用率不均衡;
  2. 当一个文件系统/分区装满时, 是不能对其进行扩容的, 只能采用重新分区/建立文件系统, 重新分区会丢失数据, 就要
    ① 做数据的迁移和备份;
    ② 或者把分区中的数据移到另一个更大的分区中;
    ③ 或者采用符号连接的方式使用其它分区的空间 —— 都非常麻烦;
  3. 如果要把硬盘上的多个分区合并在一起使用, 只能采用重新分区的方式, —— 需要做好数据的备份与恢复.

SELinux

SELinux（Security-Enhanced Linux）是由美国国家安全局（NSA）开发的一个 Linux 内核安全模块。它为 Linux 系统提供了强制访问控制（MAC）功能，目的是提高操作系统的安全性，防止不良程序或攻击者对系统造成危害

SELinux 和 ACL 的对比

特性 SELinux ACL
控制模型 强制访问控制（MAC） 自主访问控制（DAC）
控制粒度 对进程、文件、网络端口等的 全局控制 对文件和目录的 访问控制
安全性 高，具有强制性控制，即使是 root 用户也无法绕过 相对较低，root 用户可以修改 ACL 配置，权限可被绕过
管理方式 使用策略文件和安全上下文进行管理，需要额外工具（如 semanage） 使用命令行工具（如 setfacl、getfacl）直接管理文件和目录
配置复杂度 配置复杂，适合需要强安全性控制的环境 配置简单，适合文件级别的用户权限管理
适用场景 需要强制控制、进程间权限管理的高安全性环境 多用户环境中的文件和目录权限控制
功能 控制进程与文件、进程与进程之间的访问权限 控制文件和目录对不同用户的访问权限
示例 设置文件上下文：
sudo semanage fcontext -a -t httpd_sys_content_t "/var/www/html(/.*)?"
sudo restorecon -Rv /var/www/html		 设置文件 ACL：
sudo setfacl -m u:username:rwx file.txt

电烙铁使用

一、所需材料

  • 电烙铁（温度可调，280℃~350℃）
  • 焊锡丝（含助焊剂芯最佳）
  • 助焊剂（焊锡丝无助焊芯时使用）

二、操作步骤

  1. 预热电烙铁

    • 将电烙铁调至目标温度（280℃~350℃）
    • 确保温度足够，否则焊锡无法顺利熔化

  2. 准备焊点

    • 清理焊接表面，有氧化层时用砂纸、钢丝刷或助焊剂清理
    • 表面干净、平整

  3. 涂助焊剂

    • 在焊接部位涂薄层助焊剂（若焊锡丝含助焊芯，可省略）

  4. 加热焊接点

    • 烙铁烙头接触焊点，同时靠近焊锡丝，让焊锡熔化流入焊点
    • 注意：不要先加热焊锡丝再碰焊点，应让焊点和焊锡同时受热

  5. 焊锡流动与覆盖

    • 焊锡应完全覆盖焊点，形成均匀焊珠
    • 焊接时间过长会烧坏元件，过短焊锡不牢固

  6. 冷却与检查

    • 移开电烙铁，自然冷却
    • 检查焊点是否光亮、均匀，无虚焊或桥连

三、关键因素注意

  1. 电烙铁温度

    • 温度过低 → 焊锡不融化、附着不牢
    • 温度过高 → 烧坏元件、氧化焊点

  2. 电烙铁功率

    • 功率太低 → 加热慢、受热面积不足
    • 功率太高 → 不易控制温度
    • 一般30~60W适合大部分电子焊接

  3. 受热面积

    • 烙铁烙头与焊点充分接触
    • 大焊点用大烙铁头，小元件用尖头烙铁

  4. 表面状态

    • 有氧化层 → 焊锡难附着 → 需清理或涂助焊剂

所需硬件

核心部件

  • 光伏组件（Solar PV Modules / Solar Panels）
    作用：把太阳光转为直流电（DC）。
    要点：选单晶硅、高转换效率（≥19% 更优）、带 PID 抗衰能力。组件功率按屋顶面积/需求选择（如 300–540 W/panel）。
    数量 = 目标系统容量（kW） ÷ 单板功率（kW）。

  • 混合逆变器（Hybrid Inverter / PV Inverter with ESS）
    作用：DC→AC、MPPT、管理电池充放电、并网与离网切换。
    要点：支持双向充放电、并网认证、离网/备电输出、通信（RS485 / CAN / Wi-Fi）、峰值输出能力要匹配家中最大同时功率。
    常见规格：3kW / 5kW / 10kW 等；直流输入电压/最大 MPPT 电流要能接入你的 PV 阵列。

  • 储能电池（Battery Bank） — 推荐 LiFePO4（磷酸铁锂）
    作用：存储白天多余电能，用于夜间或停电时供电。
    要点：选择带 BMS 的电池包；标注循环寿命（≥3000 次@80% DOD 更好）；额定电压（48V 系统常见）或模块化 400V 系统（取决逆变器）。
    容量建议（家庭参考）：5 kWh / 10 kWh / 20 kWh。

  • 电池管理系统（BMS）
    作用：电池保护（过充、过放、均衡、温度保护）和与逆变器通讯。
    要点：必须与电池和逆变器兼容，支持报警与远程通信。

地基阶段注意事项

防水处理

  • 关键节点加强防水：厨房、卫生间的地面与墙面交界处，务必采用聚氨酯或水泥基防水涂料，并向上返高≥30cm。
  • 设置防潮层：一楼地面下应预铺防潮膜（如PVC或自粘式沥青卷材），有效阻隔地气上升。
  • 户外地面坡度设计：屋外地坪应高于周边排水沟至少10cm，地面向外倾斜2~3%，防止雨水回流。

热水/供水布局

  • 热水管道预埋：采用PPR或PE-RT热水专用管，外包保温棉，防止热量流失。
  • 太阳能热水系统预留：
    • 上水、回水、溢水管道预埋；
    • 储水箱位置尽量设于高处以确保自然水压；
  • 泵系统智能化：
    • 安装断电自停功能，避免干烧；
    • 可选变频恒压泵以提升用水舒适度与节能效果。

防蚊虫叮咬

  • 高离地设计：将地面层抬高 40–80 cm，有效减少地面湿气与虫害滋生源。
  • 水沟与排水坡度设计：避免积水死角，是预防蚊虫滋生的核心设计。
  • 屋顶排水顺畅设计：设置排水沟槽、防堵落叶网，防止雨后积水孳生蚊子。
  • 无死角阴暗空间：减少蚊虫栖息区域，尤其在厨房、厕所、天花板边缘。

节能导向的地基设计

  • 保温层预留：在地坪施工前铺设XPS 挤塑板或泡沫混凝土，减少地面热传导；
  • 太阳能系统预布线：地基预留光伏电缆通道、电池房管线槽；
  • 雨水收集系统接口：预埋雨水排入储水池的管道，用于冲厕、浇花等二次利用。

水资源节能设计方案

级别 水质要求 用水场景 推荐水源
✅ 一级水 可直接饮用 饮水、做饭 自来水 / 反渗透（RO）处理后的雨水或地下水

✅ 三级水 无皮肤接触 冲厕、洗衣机、室内清洁 雨水+普通过滤 / 灰水处理出水
✅ 四级水 非接触景观水 浇花、冲地、喷泉、景观池补水 荷花池雨水原水 / 简单过滤的灰水

🔧 每级水处理建议方案

  • 🥇 一级水（饮用）
    • 推荐：自来水 或
      • RO膜+UV消毒雨水系统
      • 末端设置净水龙头（饮水分开）
    • 用于：厨房饮用水、泡茶、做饭
  • 🥈 二级水（洗澡 / 泳池）
    • 雨水处理需：
      • 多级砂滤 + 活性炭 + 紫外线（或臭氧）
    • 池水需循环过滤系统 + 定期杀菌
  • 🥉 三级水（冲厕 / 洗衣）
    • 雨水+简单过滤即可；
    • 或使用处理后的灰水（洗澡水）
  • 🧯 四级水（浇花 / 景观）
    • 不需杀菌；
    • 可直接从荷花池抽取或雨水初滤水

🌧️ 雨水管理与回用

  • 屋顶雨水收集系统（落水管 + 滤网 + 蓄水桶）。
  • 灰水（洗澡/洗衣水）过滤后回用：冲厕、浇花。
  • 智能水表 + 水流实时监控，漏水报警。

🚿 节水设备与生活用水优化

  • 节水型洁具（双档马桶、节水花洒、起泡龙头）。
  • 可降解洗涤剂（适配灰水系统，避免堵塞/污染）。
  • 花园微滴灌系统，减少水耗、提高效率。

♻️ 污水处理与再利用

  • 处理方式：

    • 三格式化粪池：基础版，适用于1~3户。
    • 一体化小型污水处理设备：出水可灌溉/冲厕。
    • MBR 膜处理系统：可达中水标准，回用广泛。

  • 运行优化：

    • 使用电曝气或风曝气系统提升处理效率。
    • 搭配太阳能曝气机节能运行。

  • 回用建议：

    • 出水仅用于非饮用途，如景观、花园、厕所冲水。
    • 设置绿植过滤带/湿地吸收，提升生态安全性。

室内装修阶段注意事项

🚽 卫生间设计

  • 洗手台面应有微斜排水设计，避免水滞留。
  • 地面坡度 ≥1.5%，设置地漏 ≥2个，防止积水。
  • 建议做干湿分离（玻璃隔断/推拉门）。

🪟 窗户设计

  • 落地窗滑轮推荐安装于上方，更防尘易维护。
  • 建议使用中空双层玻璃 + 隔热断桥铝材料。
  • 窗户加装密封条，提升隔音与保温性能。

🍳 厨房设计

  • 选 ≥17m³/min 吸力油烟机，配备止回阀。
  • 抽油烟口向外，带防虫防雨罩。
  • 橱柜下方设计通风口或百叶门，防潮防霉。

照明与配电系统设计

配电安全

  • 强电/弱电分离布线，避免干扰，布线使用阻燃线管。
  • 所有空调、热水器、厨房电器应设置独立回路 + 空气开关；
  • 建议安装漏电保护器（ELCB）+ 电涌保护器（SPD），应对雷击等风险。

照明布局

  • 主照明建议使用LED 吸顶灯或筒灯，高效节能；
  • 卧室、走廊、卫生间建议搭配感应灯或夜灯，便捷又节能；
  • 考虑预埋智能照明控制系统（如 Zigbee、Wi-Fi、KNX），后期可接入 Home Assistant 等智能中枢。

🌿 节能建筑设计辅助方案

🍃 通风与遮阳设计

  • 中庭通风井、开窗对流、屋檐挑出 ≥0.8m。
  • 百叶窗与高位排气窗配合，增强排热与遮阳效果。

🧱 材料与结构选择

  • 使用本地天然建材（竹、柚木、红土砖），低碳环保。
  • 坡屋顶利于排水与热对流。
  • 设置独立“设备房”：集中布置电池、泵、过滤设备等，方便维护与检修。

✅ 附加建议（施工实用）

  • 插座预留合理，避免后期拖线。
  • 弱电布线提前规划：摄像头、Wi-Fi、门禁等。
  • 屋顶可加绿植或设凉亭，降温又美观。
  • 建议双管排水（黑水/灰水分离），提升回用系统效率。

软件与模块对应

对应你流程里的各个步骤：

  1. 麦克风输入
    • 用 pyaudio / sounddevice 采集音频流。
    • 设置为 16kHz 单声道 PCM。
  2. Ring Buffer 缓存
    • 可以用 collections.deque 或者 sounddevice.RawInputStream 自带的回调缓存。
    • 缓存 1~3 秒的音频，保证唤醒词检测和语音片段提取。
  3. 唤醒词检测
    • 轻量：Porcupine（低资源占用，树莓派友好）
    • 可训练：Mycroft Precise
    • 自定义词：Vosk + KeywordSpotter
  4. 提取音频片段（1~2秒）
    • 当检测到唤醒词，立刻把 Ring Buffer 里的最后 1~2 秒 dump 出来保存为 .wav。
  5. 说话人识别（X-vector）
    • 依赖 pyannote.audio 或 SpeechBrain，输入音频片段，输出 speaker embedding → 与本地数据库比对。
    • 树莓派 4/5 能跑，但建议用轻量模型或外接 USB TPU（Coral USB Accelerator）。
  6. 身份确认
    • 如果 embedding 相似度 > 阈值（如 0.75），则确认说话人。
    • 否则忽略唤醒，避免被陌生人触发。
  7. 完整语音识别（ASR）
    • 用 Vosk（支持离线运行，中文/英文等都有预训练模型）。
    • Vosk-pi 版本可在树莓派直接跑，速度较慢，但可以用小模型（如 vosk-model-small-cn-0.3）。

目标：构建家庭阳台微型生态闭环

  • 厨余 → 肥料 | 肥料水
  • 鱼缸 → 植物营养水

整体生态结构

阳台分区规划

🅐 厨余处理区（源头）

  • 密封式堆肥桶（防虫防臭）
  • 发酵液肥瓶（带放气）

🅑 土培区（主产出）

  • 🌱幼苗成长区
  • 花盆 / 种植箱
  • 使用自制堆肥 + 蛋壳粉

🅒 水培区（吸收营养水）

  • 静态水培瓶 / PVC 水培槽
  • 直接使用鱼缸换水

🅓 鱼缸区（生态核心）

  • 鱼缸 + 过滤 + 水草
  • 稳定供给氮源

厨余产生利用

分类原则

  • 能变肥的一定变肥
  • 需处理的先处理再进生态
  • 高风险物质分流

① 可直接堆肥（阳台生态能源）

植物性湿垃圾

  • 水果皮 / 果渣
  • 蔬菜边角 / 烂叶
  • 米饭、面食（少量）
  • 茶渣、咖啡渣

❌ 避免：

  • 高油、高盐、重辣

👉 处理方式：

懒人阳台堆肥操作流程（无液肥版）

  1. 底层铺土

    • 使用普通园土，厚度覆盖桶底即可

  2. 投入湿垃圾

    • 做饭前不要的菜叶、果渣、茶渣等

  3. 覆盖土层

    • 完全盖住湿垃圾，确保看不到垃圾

② 可加工再利用（处理后进生态）

🥚 鸡蛋壳

  • 清洗 → 晾干 → 炒干 → 碾粉
  • 作用：补钙、调节酸碱、防虫

🦐 虾壳 / 蟹壳（进阶）

  • 煮去盐 → 晒干 → 粉碎
  • 少量混土（缓释钙、甲壳素）

③ 可再利用但不进生态

🛍 塑料袋 / 包装袋

  • 分类收纳
  • 用途：垃圾袋、防潮垫、临时种植袋

④ 必须丢弃（不进阳台系统）

  • 重油肉汤
  • 高盐腌制品
  • 化学污染食物

肥料获取-厨房废料

获取方法

  1. 多准备土壤
  2. 每次吃饭前，将果渣、菜渣丢进肥料桶
  3. 在废料上铺一层土
  4. 重复：丢果渣/菜渣 → 铺土，直至桶满

桶的准备

  • 桶A：储存土壤
  • 桶B：堆肥桶，用于发酵厨房废料

初阶土培

适合种植：蒜

步骤

  1. 水培阶段
  • 果核 - 清理核上的果肉残渣避免菌种繁殖污染幼苗的水质
  • 根系 - 先用水培方式培育出蔬菜根系
  1. 转入土壤
  • 将水培成苗的蔬菜移入土壤
  • 适量添加自制肥料，提高营养

  • 环境控制：建议放在阳台/封闭阳光房中

模块 功能 建议型号
