# [expanded] [blog] vue2 对比 vue3 > 原始问题: [blog] vue2 对比 vue3 # Vue2 vs Vue3 核心差异技能点清单 > 场景占位: 组件用 /,数据用 ,方法用 > 阅读顺序: 扫标题 → 记住反直觉 3-5 条即可动手 --- ## 1. setup() 替代 beforeCreate/created,不要再显式声明这俩钩子 - **规则**: Vue3 的 setup() 在组件实例创建前执行,完全覆盖 beforeCreate/created 时机 - **为什么**: setup() 执行时 this 还未绑定,访问不到组件实例,强制你用 Composition API 思维而非 Options API - **踩坑**: 在 setup() 里写 this. 永远是 undefined,必须用 getCurrentInstance() 或直接返回响应式变量 - **例外**: 迁移老代码时可保留 Options API,但 setup 和 created 同时存在会让执行顺序混乱 ## 2. 生命周期钩子加 on 前缀且必须在 setup() 内导入使用 - **规则**: Vue3 钩子改名(mounted → onMounted)且必须从 vue 导入,不能直接写在 export default 根级 - **为什么**: Composition API 强制树摇优化,未使用的钩子不会打包,Options API 写法会把所有钩子都打进 bundle - **踩坑**: 忘记 import { onMounted } 会报 onMounted is not defined,而 Vue2 的 mounted 是隐式可用的 - **例外**: 使用 `
