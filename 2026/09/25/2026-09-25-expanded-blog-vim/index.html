Vim 编辑器技能点清单

场景占位: 编辑 , 修改 , 搜索
阅读顺序: 扫标题 → 记住反直觉 3-5 条即可动手

1. 打开文件默认进命令模式,不能直接打字

  • 规则: 打开文件后先按 i 进编辑模式,编辑完按 Esc 回命令模式
  • 为什么: Vim 设计哲学是”阅读时间 > 编辑时间”,命令模式让光标移动和批量操作更高效
  • 踩坑: 新手打开文件直接敲字符,结果触发了删除/跳转等命令,文件被改得面目全非
  • 例外: vim -c startinsert <FILE> 可直接进编辑模式,但失去了 Vim 核心优势

2. dd 是剪切不是删除,误删内容还在剪贴板

  • 规则: dd 删除行后用 p 可粘贴回来,真删除用 "_dd (黑洞寄存器)
  • 为什么: Vim 所有删除操作都会进剪贴板,方便移动文本,但会覆盖之前复制的内容
  • 踩坑: 复制了 A 行,删除 B 行后想粘贴 A,结果粘贴出 B

3. 末行模式替换默认只替换每行第一个匹配

  • 规则: 全局替换必须用 :%s/<OLD>/<NEW>/g,缺 % 只改当前行,缺 g 只改每行首个
  • 为什么: Vim 继承 sed 语法,默认保守操作避免误改
  • 踩坑: :s/http/https/ 只改了当前行第一个 http,其他 999 行未动

4. 撤销后再编辑会丢失被撤销的分支

  • 规则: 撤销 (u) 后想恢复用 Ctrl+r,但撤销后编辑新内容会永久丢失被撤销的历史
  • 为什么: Vim 默认是线性 undo 树,不保留分支 (除非开启 undofile)
  • 踩坑: 撤销 5 步,改了一个字,想回到撤销前的状态,发现那 5 步永远找不回了
  • 例外: :earlier 4m 可基于时间回溯,但需要 undofile 持久化

5. 分屏后 :q 只关当前窗口不退出 Vim

  • 规则: 分屏环境用 :qa 退出所有窗口,:q 只关当前分屏
  • 为什么: Vim 把每个分屏视为独立窗口,:q 是 quit window 不是 quit vim
  • 踩坑: 开了 3 个分屏,按 :q 以为退出了,结果 Vim 还在后台占着文件锁

6. 搜索后高亮不会自动消失

  • 规则: / 搜索后用 :noh 取消高亮,或 :set nohlsearch 永久关闭
  • 为什么: Vim 认为高亮是有用的视觉提示,不会因为光标移动而清除
  • 踩坑: 搜索 error 后满屏黄色高亮,看其他内容时干扰视线

7. D 删除到行尾但不删除换行符

  • 规则: D 等价于 d$,删除光标到行尾内容但保留空行,dd 才删整行含换行符
  • 为什么: Vim 区分”行内容”和”行本身”,D 是行内操作,dd 是行操作
  • 踩坑: 用 D 想删除整行,结果留下一堆空行

8. :w <PATH> 另存为不会切换当前编辑文件

  • 规则: :w <NEW_FILE> 后当前缓冲区仍是原文件,要切换需 :e <NEW_FILE>
  • 为什么: Vim 的 :w 只是写入操作,不改变缓冲区绑定
  • 踩坑: 另存为 后继续编辑,以为在改备份,实际还在改原文件

9. 多文件编辑时 :bn/:bp 切换的是缓冲区不是标签页

  • 规则: vim <FILE1> <FILE2> 打开的是缓冲区列表,:bn/:bp 切换,:ls 查看列表
  • 为什么: Vim 的 buffer/window/tab 是三层概念,多文件默认进 buffer 不是 tab
  • 踩坑: 以为 :bn 会像浏览器切标签,结果当前窗口内容直接被替换

10. yy 复制整行包括换行符

  • 规则: yy 复制后 p 粘贴会插入新行,想粘贴到行内用 ^y$ 只复制内容不含换行
  • 为什么: Vim 的行操作 (yy/dd/p) 都是面向”完整行”的,包括不可见的换行符
  • 踩坑: 复制配置行想拼接成一行,p 后发现自动换行了

11. 分屏尺寸调整只对当前窗口生效

  • 规则: Ctrl+w +/- 调整当前窗口高度,其他窗口会自动压缩,Ctrl+w = 平均分配
  • 为什么: Vim 终端空间有限,调整一个窗口必然挤压其他窗口
  • 踩坑: 调大上方窗口后,下方窗口只剩 1 行看不清内容

12. :set nu 只在当前会话生效

  • 规则: 临时设置用 :set nu,永久生效需写入 ~/.vimrc
  • 为什么: Vim 启动时只读取配置文件,运行时的 :set 命令不会持久化
  • 踩坑: 每次打开文件都要手动 :set nu,以为 Vim 记不住设置

13. r 替换单字符后自动回命令模式,R 进入持续替换模式

  • 规则: 改一个字符用 r<NEW_CHAR>,改多个字符用 R 进替换模式后按 Esc 退出
  • 为什么: r 是原子操作,R 是模式切换,设计上避免误操作
  • 踩坑: 想连续替换多个字符,按 r 后只改了一个就停了

14. 分屏移动光标和移动分屏是不同的快捷键

  • 规则: Ctrl+w hjkl 移动光标到其他分屏,Ctrl+w HJKL (大写) 移动分屏本身
  • 为什么: Vim 区分”我去哪个窗口”和”把窗口移到哪”,大小写区分操作对象
  • 踩坑: 想把右侧分屏移到左侧,按 Ctrl+w h 结果只是光标跳过去了

15. :!<COMMAND> 执行外部命令会暂停 Vim

  • 规则: :!ls 执行后需按回车返回 Vim,想在 Vim 内看输出用 :r !<COMMAND>
  • 为什么: Vim 把控制权交给 shell,执行完等待用户确认再返回
  • 踩坑: 执行 :!<LONG_SCRIPT> 后黑屏,以为 Vim 卡死了,其实在等按键

🔥 5 秒必记 5 条

  1. 打开文件按 i 才能打字,Esc 回命令模式
  2. 全局替换必须 :%s/<OLD>/<NEW>/g,缺 % 或 g 都不是全局
  3. dd 是剪切不是删除,误删用 p 粘贴回来
  4. 撤销后编辑新内容会丢失被撤销的分支
  5. 分屏环境 :q 只关当前窗口,:qa 才退出 Vim
