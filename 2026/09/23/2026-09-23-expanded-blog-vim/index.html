Vim 编辑器核心技能点清单

场景占位: 文件路径用 <FILE_PATH>, 关键词用 <KEYWORD>, 新内容用 <NEW_TEXT>
阅读顺序: 扫标题 → 记住反直觉 3-5 条即可动手

1. 默认进入命令模式,所有操作从模式切换开始

  • 规则: 打开文件后处于命令模式,按 i/a/o 进编辑模式,按 Esc 回命令模式,按 : 进末行模式
  • 为什么: 新手最大困惑是”为什么按键没反应” — 因为在错误模式下,命令模式不能直接输入文本
  • 踩坑: 在命令模式下狂按字母键会触发各种删除/复制操作,导致文件内容混乱
  • 例外: vim -R <FILE_PATH> 以只读模式打开时,编辑模式受限

2. dd 是剪切不是删除,误删内容按 p 立即找回

  • 规则: dd 删除当前行但内容在剪贴板,p 粘贴到光标下一行,P 粘贴到上一行
  • 为什么: Vim 的”删除”本质是剪切,这与其他编辑器的 Delete 键语义完全不同
  • 踩坑: 连续 dd 多行后按 p 会一次性粘贴所有行,不是只粘贴最后一行
  • 例外: "_dd 真正删除当前行且不进剪贴板(黑洞寄存器)

3. 撤销用 u,重做用 Ctrl+r,但撤销是树状不是线性

  • 规则: u 撤销上一步,Ctrl+r 重做,:earlier 4m 回到 4 分钟前状态
  • 为什么: Vim 的撤销是分支树(undo tree),撤销后再编辑会创建新分支,不会丢失被撤销的内容
  • 踩坑: 撤销 5 步后编辑新内容,再按 Ctrl+r 不会恢复刚才撤销的内容,而是沿新分支前进
  • 例外: :undolist 查看所有分支,:undo 5 跳到指定变更号

4. 全局替换必须加 %,否则只替换当前行

  • 规则: :%s/<KEYWORD>/<NEW_TEXT>/g 替换全文所有匹配,:s/<KEYWORD>/<NEW_TEXT> 只替换当前行第一个
  • 为什么: % 表示全文范围,g 表示行内全局,两者缺一都会导致替换不完整
  • 踩坑: :s/<KEYWORD>/<NEW_TEXT>/g 只替换当前行所有匹配,不是全文,90% 新手会漏 %
  • 例外: :5,10s/<KEYWORD>/<NEW_TEXT>/g 只替换 5-10 行

5. 分屏后光标移动用 Ctrl+w 前缀,不是方向键

  • 规则: :sp <FILE_PATH> 水平分屏,:vsp <FILE_PATH> 垂直分屏,Ctrl+w h/j/k/l 切换窗口
  • 为什么: 方向键在分屏中只移动当前窗口内的光标,不会跨窗口,必须用 Ctrl+w 组合键
  • 踩坑: Ctrl+w c 关闭当前窗口,Ctrl+w q 关闭窗口且最后一个时退出 Vim,容易误操作丢失未保存内容
  • 例外: Ctrl+w w 循环切换到下一个窗口,不需要记方向

6. 行号跳转用 :<行号>,不是 G 加数字

  • 规则: :42 跳到第 42 行,gg 跳到首行,G 跳到末行,42G 也能跳到第 42 行
  • 为什么: : 进入末行模式后直接输入数字是最快的精确跳转方式,比命令模式下的 42G 少一次模式切换
  • 踩坑: 命令模式下输入 42 后按 G 会跳转,但输入过程中数字会显示在屏幕右下角,容易误以为没生效
  • 例外: 42gg 和 42G 等价,但 gg 更常用于首行跳转

7. 查找后按 n/N 跳转,不是重复输入 /关键词

  • 规则: /<KEYWORD> 向下查找,?<KEYWORD> 向上查找,n 下一个匹配,N 上一个匹配
  • 为什么: 查找后 Vim 会记住关键词,n/N 复用上次查找,避免重复输入
  • 踩坑: 查找后直接按 n 会跳转,但如果之前没查找过,n 会报错”No previous search”
  • 例外: * 查找光标下的单词,# 反向查找,比手动输入 /<KEYWORD> 更快

8. 强制退出用 :q!,不是 :wq! (后者会强制保存)

  • 规则: :q! 不保存强制退出,:wq 保存并退出,:wq! 强制保存只读文件并退出
  • 为什么: ! 的位置决定强制的对象,:q! 强制退出,:w! 强制写入,:wq! 两者都强制
  • 踩坑: 只读文件用 :wq 会报错,必须用 :wq! 或先 chmod 改权限,但 :wq! 可能覆盖重要文件
  • 例外: :x 等价于 :wq,但只在文件有修改时才写入,更安全

9. 翻屏用 Ctrl+f/b,不是 PgDn/PgUp (后者依赖终端)

  • 规则: Ctrl+f 向下翻页,Ctrl+b 向上翻页,Ctrl+d 向下半页,Ctrl+u 向上半页
  • 为什么: Ctrl+f/b 是 Vim 原生快捷键,在所有终端都生效,PgDn/PgUp 依赖终端模拟,SSH 环境可能失效
  • 踩坑: Ctrl+f 在某些终端会被拦截为”查找”,导致 Vim 收不到按键,需要重新映射终端快捷键
  • 例外: zz 将当前行移到屏幕中央,zt 移到顶部,zb 移到底部,比翻屏更精确

10. 多文件切换用 :bn/:bp,不是 :open (后者会新开窗口)

  • 规则: vim <FILE_A> <FILE_B> 同时打开多文件,:bn 切换到下一个,:bp 切换到上一个,:files 查看列表
  • 为什么: :open <FILE_PATH> 会在当前窗口打开新文件,但不会加入缓冲区列表,:bn/:bp 无法切换
  • 踩坑: :e <FILE_PATH> 编辑新文件会替换当前缓冲区,未保存内容会丢失,必须先 :w 保存
  • 例外: :b <FILE_PATH> 直接跳转到指定文件,支持 Tab 补全文件名

11. 行首用 ^,行尾用 $,不是 Home/End (后者含空格)

  • 规则: ^ 跳到行首第一个非空字符,0 跳到行首第一列,$ 跳到行尾
  • 为什么: ^ 跳过缩进直达有效内容,比 0 更符合编程场景,Home 键行为因终端而异
  • 踩坑: $ 在行尾时光标在最后一个字符上,不是字符后,按 a 才能在行尾追加内容
  • 例外: g_ 跳到行尾最后一个非空字符,避免尾部空格干扰

12. 复制用 yy,不是 Ctrl+c (后者会中断 Vim)

  • 规则: yy 复制当前行,5yy 复制 5 行,p 粘贴到下一行,P 粘贴到上一行
  • 为什么: Ctrl+c 在终端中是中断信号,会强制退出 Vim 当前操作,不是复制
  • 踩坑: yy 复制的内容在 Vim 内部剪贴板,无法用系统 Ctrl+v 粘贴到其他程序,需要用 "+yy 复制到系统剪贴板
  • 例外: yw 复制一个单词,y$ 复制到行尾,y^ 复制到行首

13. 临时显示行号用 :set nu,永久配置写 ~/.vimrc

  • 规则: :set nu 显示行号,:set nonu 隐藏行号,写入 ~/.vimrc 后每次打开生效
  • 为什么: 末行模式的 :set 命令只在当前会话生效,关闭 Vim 后失效,必须写配置文件持久化
  • 踩坑: :set number 和 :set nu 等价,但 :set nonumber 必须完整拼写,:set nonu 是缩写
  • 例外: :set rnu 显示相对行号,当前行显示绝对行号,其他行显示相对距离,适合快速跳转

14. 替换单个字符用 r,替换模式用 R,不是删除后插入

  • 规则: r<字符> 替换光标下字符,R 进入替换模式连续替换,Esc 退出
  • 为什么: r 替换后自动回到命令模式,比 x 删除 + i 插入快 2 个按键,R 模式类似 Insert 键覆盖输入
  • 踩坑: r 只能替换单个字符,替换多字符必须用 R 模式或 cw 删除单词后输入
  • 例外: ~ 切换光标下字符的大小写,g~w 切换整个单词大小写

15. 执行外部命令用 :!,不是退出 Vim 再执行

  • 规则: :!<外部命令> 在 Vim 内执行 Shell 命令,:r !<命令> 将命令输出插入当前位置
  • 为什么: 避免退出 Vim 丢失编辑状态,:!ls 查看目录,:!make 编译代码,结果显示后按回车返回 Vim
  • 踩坑: :!<命令> 执行后终端输出会覆盖 Vim 界面,必须按回车刷新,:r !<命令> 会直接插入内容到文件
  • 例外: :sh 临时进入 Shell,exit 返回 Vim,保留编辑状态
