Vim 编辑器核心技能点清单

场景占位: 编辑 , 修改 配置, 查找
阅读顺序: 扫标题 → 记住反直觉 3-5 条即可动手

1. 默认进入命令模式,所有操作从这里开始

  • 规则: 打开文件后处于命令模式,按 i/a/o 进入编辑模式,按 : 进入末行模式,按 Esc 回命令模式
  • 为什么: 新手最大困惑是”为什么按键没反应” — 因为在命令模式下字母是快捷键不是输入字符
  • 踩坑: 在命令模式下狂按字母想输入内容,结果触发了删除/复制等操作把文件改乱
  • 例外: vim -R <FILE> 只读模式下无法进入编辑模式

2. 用 dd 剪切而非删除,删除的内容自动进剪贴板

  • 规则: dd 删除当前行并放入剪贴板,p 粘贴,5dd 删除 5 行
  • 为什么: Vim 没有”纯删除”概念,所有删除都是剪切,这是多数编辑器不同的设计
  • 踩坑: 用 dd 删除后又 yy 复制别的内容,导致刚删的东西被覆盖无法找回

3. 末行模式替换必须理解 % 和 g 的组合含义

  • 规则: :s/old/new/ 只替换当前行第一个,:%s/old/new/g 替换全文所有
  • 为什么: % 表示全文范围,g 表示行内全局,缺一个都达不到”全部替换”效果
  • 踩坑: 用 :%s/old/new/ 以为能全部替换,结果每行只替换了第一个匹配
  • 例外: :5,10s/old/new/g 只替换 5-10 行

4. 撤销用 u,重做用 Ctrl+r,不是 Ctrl+z

  • 规则: 命令模式下按 u 撤销,Ctrl+r 重做(redo)
  • 为什么: Ctrl+z 在 Vim 里是挂起进程(放到后台),不是撤销,新手常按错导致 Vim “消失”
  • 踩坑: 按 Ctrl+z 后终端回到 shell,以为 Vim 崩溃了,实际用 fg 可恢复
  • 例外: :earlier 4m 可回到 4 分钟前的状态,比逐次 u 更高效

5. 强制退出用 :q!,保存退出用 :wq,别混用 :x

  • 规则: :q! 不保存强制退出,:wq 保存后退出,:x 仅在有修改时保存退出
  • 为什么: :x 和 :wq 行为不同 — :x 不会更新文件时间戳如果没修改,影响 Makefile 等依赖时间戳的工具
  • 踩坑: 用 :wq 退出未修改的文件,导致文件 mtime 更新触发不必要的重新编译

6. 行首用 ^ 跳到第一个非空字符,0 才是绝对行首

  • 规则: ^ 跳到行首第一个非空白字符,0 跳到行首第 0 列,$ 跳到行尾
  • 为什么: 代码编辑时 ^ 更实用(跳过缩进),但配置文件有时需要 0 定位到注释符 #
  • 踩坑: 在有缩进的代码里按 0 后按 i 插入,结果在缩进前插入破坏了格式

7. 分屏后用 Ctrl+w 前缀操作,不是 Ctrl+s/v

  • 规则: :sp 横向分屏,:vsp 纵向分屏,Ctrl+w 后按 hjkl 切换窗口,Ctrl+w c 关闭当前窗口
  • 为什么: Ctrl+w 是 Vim 窗口操作的统一前缀,所有分屏操作都从这里开始
  • 踩坑: 按 Ctrl+w 后停顿超过 1 秒,Vim 会等待下一个按键,新手以为卡死了
  • 例外: Ctrl+w w 循环切换窗口,比记忆 hjkl 方向更快

8. 搜索用 / 向下找,? 向上找,n 下一个,N 反向

  • 规则: /pattern 向下搜索,?pattern 向上搜索,n 跳到下一个匹配,N 跳到上一个
  • 为什么: n 的方向取决于你用 / 还是 ?,不是固定”向下”,这是反直觉的
  • 踩坑: 用 / 搜索后按 N 以为是”上一个”,结果是反向(向上)继续找,跳过了下面的匹配

9. 复制整行用 yy,复制到行尾用 y$,不是选中后复制

  • 规则: yy 复制当前行,5yy 复制 5 行,y$ 复制到行尾,p 粘贴
  • 为什么: Vim 的复制是基于动作(motion)而非选区,y 后面跟移动命令决定复制范围
  • 踩坑: 想复制半行内容,用 yy 复制了整行,粘贴时多出换行符
  • 例外: 可视模式下 v 选中后 y 复制,但效率低于直接用 motion

10. 显示行号用 :set nu,永久生效需写 ~/.vimrc

  • 规则: :set nu 临时显示行号,:set nonu 关闭,写入 ~/.vimrc 永久生效
  • 为什么: 末行模式的 set 命令只在当前会话有效,关闭文件后失效
  • 踩坑: 每次打开文件都要 :set nu,不知道可以写配置文件

11. 多文件编辑用 :bn/:bp 切换,不是关了重开

  • 规则: vim <FILE1> <FILE2> 打开多文件,:bn 切换到下一个,:bp 切换到上一个,:files 查看列表
  • 为什么: Vim 的 buffer 机制允许同时打开多个文件在后台,比反复 :q 再 vim 高效
  • 踩坑: 修改了 未保存就 :bn,Vim 会报错阻止切换,需 :w 或 :set hidden 允许

12. 替换单个字符用 r,连续替换用 R 进入替换模式

  • 规则: r 后按新字符替换光标处一个字符,R 进入替换模式连续覆盖输入,Esc 退出
  • 为什么: r 不进入编辑模式,替换后自动回命令模式,改一个字符最快
  • 踩坑: 用 i 删除再输入来”替换”,多按了 3 个键

13. 翻屏用 Ctrl+f/b,翻半屏用 Ctrl+d/u

  • 规则: Ctrl+f 向下翻整屏,Ctrl+b 向上翻整屏,Ctrl+d/u 翻半屏
  • 为什么: 翻半屏时光标保持在屏幕中间,上下文不丢失,查看日志时更实用
  • 踩坑: 只知道 PgDn/PgUp,不知道 Ctrl+d/u 可保留部分上下文

14. 执行外部命令用 :!<COMMAND>,不用退出 Vim

  • 规则: :!ls 执行 shell 命令,:r !date 把命令输出插入到当前位置
  • 为什么: 编辑配置文件时可以 :!systemctl restart <SERVICE> 直接重启服务验证
  • 踩坑: 用 Ctrl+z 挂起 Vim 切到 shell 执行命令再 fg,多了 2 步操作

15. 分屏尺寸调整用 Ctrl+w = 均分,Ctrl+w +/- 微调

  • 规则: Ctrl+w = 让所有窗口等高/等宽,Ctrl+w 10+ 增加 10 行高度
  • 为什么: 对比查看日志时需要调整窗口大小,默认分屏可能一个太小看不清
  • 踩坑: 不知道能调整尺寸,手动关了重新 :sp 试图改变比例

🔥 5 秒必记 5 条

  1. 打开文件在命令模式,按 i 才能输入,按 Esc 回命令模式
  2. :wq 保存退出,:q! 不保存强制退出,别按 Ctrl+z
  3. dd 是剪切不是删除,p 粘贴,u 撤销,Ctrl+r 重做
  4. :%s/old/new/g 全文替换,缺 % 只替换当前行,缺 g 每行只替换第一个
  5. /pattern 搜索,n 下一个,:set nu 显示行号
